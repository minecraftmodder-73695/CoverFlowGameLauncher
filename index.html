Settings

Keys are stored only in this browser. Browsers block direct calls to these APIs, so most setups need the proxy. Covers you pick are saved on the device as 2:3 images when the source allows it.

Controller: D-pad or left stick browses, Up/down or LB/RB switch shelves (LB/RB skip five when shelves are off), A launches, B goes back, Y shows details, X edits, RT shuffles, Start opens settings. Inside a web game, hold Select + Start to exit. Press any button once so Safari detects the controller.

Keyboard: Left/Right browse (Home, End, PageUp, PageDown jump), Up/Down switch shelves, Enter launches, I details, E edit, N new game, / or F search, R shuffle, S or , settings, Esc goes back. In dialogs, Tab moves between fields and Esc closes. In a web game, Esc exits when the page frame is not focused.
